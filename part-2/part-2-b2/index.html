1. Write an SQL query to list all students sorted by department name and GPA (ascending). The columns shown must be: department_name, student_name, and gpa.

Answer: First, I would get all the data available from the both tables or join both of them. Then filter out the 3 columns, then first sort by department name, then secondly, sort by GPA (both in ascending order). 

        
            SELECT * FROM Student Table
            FULL JOIN Department Table ON Student Table.department_id = Department Table.department.id 
            SELECT
                Student Table.department_name,
                Student Table.student_name,
                Student Table.gpa 
            ORDER BY
                department_name,
                student_name,
                gpa;

2. Write an SQL query to list all departments together with the count of students who have a GPA below 3.0.

Answer: First, get all data together from both tables. List all possible department in one column, filter out the number of students with below 3.0 gpa in each department. 

        
            SELECT * FROM Student Table
            FULL JOIN Department Table ON Student Table.department_id = Department Table.department.id 
            SELECT
                Student Table.department_name,
                COUNT(Student Table.student_id) AS below_3_gpa,
                WHERE gpa < 3.0, 
            GROUP BY department_name;

4. Write an SQL query to list all departments together with their average GPA.

Answer: First, join the data together. List the departments in one column. For each department, add all students gpa together then divide by the number of students in each department (or average if there is such a function). 

        
            SELECT * FROM Student Table
            FULL JOIN Department Table ON Student Table.department_id = Department Table.department.id 
            SELECT
                Student Table.department_name,
                ROUND(AVG(gpa), 2) AS average_gpa 
            GROUP BY department_name;

5. Write an SQL query to list all departments sorted by department name, together with the count of male and female students. Example output:

Answer: First, join the data together. List the departments in one column. For each department, sum and group the students by gender. 

        
            SELECT * FROM Student Table
            FULL JOIN Department Table ON Student Table.department_id = Department Table.department.id 
            SELECT
                Student Table.department_name,
                    SUM(CASE WHEN gender = 'men' THEN 1 ELSE 0) AS men, 
                    SUM(CASE WHEN gender = 'female' THEN 1 ELSE 0) AS women, 
            GROUP BY Student Table.gender;
